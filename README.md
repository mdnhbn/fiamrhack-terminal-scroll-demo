# FiamrHack Terminal Scroll Demo

A standalone concept demo for a terminal-led portfolio. Each section reveals its command and output line by line as you scroll into it. The page includes a restrained Matrix-style background, a motion toggle, reduced-motion support, and mobile layouts.

## Preview

Once GitHub Pages is enabled, the demo is available at `https://mdnhbn.github.io/fiamrhack-terminal-scroll-demo/`.

## Run locally

Open `index.html` in a modern browser. The page uses plain HTML, CSS, and JavaScript.

## Design notes

- Scrolling remains standard page scrolling; the page does not hijack the wheel or keyboard.
- Terminal lines appear progressively when each panel enters view.
- Motion can be paused, and system reduced-motion preferences are respected.
- The portfolio describes coursework and authorized practice accurately.
